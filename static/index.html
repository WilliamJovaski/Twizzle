    SOURCES

      HIGHLIGHTS

      Three-stage pipeline from raw MP4 to softmax.

      Web inference executes the exact same frame-sampling and normalization contract used during PyTorch training.

      01 PREPROCESS.PY

      Uniform 16-Frame Sampling

      Every frame in the uploaded clip is decoded and resized to 160×160 RGB via cv2.INTER_AREA without cropping. Exactly 16 indices are chosen uniformly with np.linspace(0, n-1, 16).

      02 ONNX RUNTIME

      3D Spatio-Temporal Convolution

      Tensors are normalized per model using deployment_meta.json statistics into shape (1, 3, 16, 160, 160) and evaluated by X3D (12.0 MB) and R(2+1)D (125.2 MB).

      03 CALIBRATION

      Temperature-Scaled Fusion

      Raw logits are divided by each model's learned temperature before softmax. In Accurate mode, calibrated probabilities from X3D and R(2+1)D are averaged 50:50.
